# RELTAK
### a working title — named for the dragon

> **Designed and Made by Relic & Ember Studios**
> *We wake worlds.*

Reltak is a browser-based high-fantasy adventure RPG. No install, no launcher,
no platform cut — it runs anywhere a modern browser does. Low-poly, stylized,
and built around one conviction above all: it's YOUR game.

## The Vision

A high-fantasy world of adventure where your character is truly yours:

- **Multiple races and classes**, chosen at creation and grown through play
- **Real character ownership** — clothing colors, proportions, a fully
  themeable UI, all player choice
- **A camera that fits the player** — one continuum from wide third person
  down to first person, switchable anytime; some will fight from the clouds,
  some from behind the eyes
- **A world that remembers** — leave the village, clear the dungeon, come
  home to a place visibly changed by what you did

## The Base — Design Foundations

**Data over code.** Every race and class is a definition file — tint,
proportions, stats, abilities, animation set — never a hardcoded branch.
New content is a new file. The creation screen, the saves, the balance
tables, and the UI all read from the same source of truth.

**Small matrix, fully tested, room to grow.** We launch with human, elf,
and orc across warrior, ranger, and mage — nine combinations, every race
able to take every class — and automated checks that build every
combination before the roster ever expands. Growth by addition, never
by rewrite.

**Saves are forward-compatible.** A character stores what it is, not what
the game knew at the time.

**The player's hand everywhere.** The same philosophy that drives character
colors drives the UI: four complete themes ship as player-selectable
preferences, because somebody's first act in a fantasy world shouldn't be
accepting someone else's interface.

**On the shoulders of giants.** D&D (1974) for the clarity of the package;
PLATO's dnd (1975) for proving it fits a screen; WoW for showing the whole
race/class matrix at once so nobody backtracks; BG3 for how far
combinatorics can go and what they cost. We steal from the best,
deliberately.
